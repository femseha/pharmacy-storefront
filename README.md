# Pharmacy Storefront Starter

واجهة HTML عربية RTL متجاوبة كبداية لمتجر صيدلي عام.

## التشغيل
افتح `index.html` في المتصفح. لا يحتاج المشروع إلى build command أو dependencies.

## قبل النشر
- أدخل الاسم القانوني للصيدلية وبيانات الترخيص.
- راجع السياسات المحلية لكل دولة مستهدفة.
- أضف المنتجات المسموح بتداولها فعليًا فقط، مع بيانات دقيقة.
- أضف سياسة الخصوصية والشحن والإرجاع ووسائل التواصل المعتمدة.

## النشر على Vercel
ارفع ملفات المشروع إلى مستودع GitHub جديد، ثم استورده من Vercel. إعدادات البناء: Framework Preset `Other`، وBuild Command فارغ، وOutput Directory `.`.
