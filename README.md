# Pharmacy Storefront Starter

واجهة HTML عربية باتجاه RTL لموقع صيدلية عام.

## التشغيل والنشر
- افتح `index.html` في المتصفح.
- المشروع ثابت HTML/CSS ولا يحتاج إلى build command.
- النشر الحالي عبر Cloudflare Pages المرتبط بمستودع GitHub.
- بعد دفع تغييرات إلى الفرع `main`، يتولى Cloudflare Pages النشر التلقائي إذا كان الربط مفعّلًا.

## قبل النشر النهائي
- أدخل الاسم القانوني للصيدلية وبيانات الترخيص الصحيحة.
- راجع القوانين ومتطلبات صرف الأدوية في كل دولة مستهدفة.
- أضف المنتجات المسموح بتداولها فقط مع بيانات دقيقة.
- أضف سياسة خصوصية وشحن وإرجاع مطابقة للخدمات الفعلية.
- لا تنشر ادعاءات طبية أو تنظيمية دون مصدر موثوق وحديث.
